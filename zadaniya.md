# Практика по Linux — работа с файлами и текстом

**Время:** 80 минут. **sudo не нужен.** Все данные — только в вашей домашней папке.

## Подготовка (2 минуты)

Запустите генератор — он создаст ваш **персональный** набор данных:

```bash
bash generate.sh
```

Данные появятся в `~/praktika`. У каждого они свои — ответы соседа вам не подойдут.

## Как сдавать ответ

Для каждого задания вы получаете ответ (число или слово) и превращаете его в
персональный «жетон сдачи»:

```bash
echo -n "$USER:ВАШ_ОТВЕТ" | sha256sum | cut -c1-12
```

Пример: если в задании 1 у вас получилось `62`, выполните
`echo -n "$USER:62" | sha256sum | cut -c1-12` и запишите полученные 12 символов
в бланк ответов напротив задания 1.

> Списать чужой ответ бесполезно: жетон привязан к вашему логину.

## Задания

### 1. Считаем файлы (find, wc)
Сколько файлов `.txt` лежит в `~/praktika/data`?
_Подсказка: `find` + `wc -l`._

### 2. Поиск по содержимому (grep)
В скольких файлах внутри `~/praktika/data` встречается слово `GOLD`?
_Подсказка: `grep -r` с флагом, который выводит только имена файлов._

### 3. Суммирование чисел (awk)
Найдите **сумму** всех чисел в файле `~/praktika/nums.txt`.
_Подсказка: `awk '{s+=$1} END{print s}'`._

### 4. Скрытые файлы (ls -a, grep)
В папке `~/praktika/notes` спрятан файл с кодовым словом (`codeword=...`).
Найдите **само слово** (то, что после `=`).
_Подсказка: обычный `ls` его не покажет. Ответ — слово, сдавайте его через жетон._

### 5. Анализ лога (awk)
В файле `~/praktika/logs/access.log` сколько запросов вернули статус **404**?
_Статус — это 9-е поле строки. Подсказка: `awk '$9==404'`._

### 6. Топ по частоте (sort, uniq)
Какой IP-адрес встречается в логе **чаще всего**? (IP — первое поле)
_Подсказка: `awk '{print $1}' | sort | uniq -c | sort -rn | head`. Ответ — сам IP._

## Задание со звёздочкой (по желанию, +балл)

### 7. Свой скрипт + доказательство работы
Напишите скрипт `~/praktika/report.sh`, который выводит одной командой:
ваш логин, количество файлов в `data/` и сумму из `nums.txt`.
Сделайте его исполняемым (`chmod +x`) и запустите.

В доказательство сдайте историю своих команд:
```bash
history | grep -E 'grep|find|awk|sort|chmod' > ~/praktika/proof.txt
```
Покажите `proof.txt` преподавателю — по нему видно ваш ход решения.
